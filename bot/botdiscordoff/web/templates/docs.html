🚀 Démarrage rapide

Mets Miaouscle Bot en place en 3 étapes :

1

Invite le bot sur ton serveur

Clique sur ce lien d'invitation et sélectionne ton serveur. Le bot demande les permissions nécessaires.

2

Configure avec /config ou le Dashboard

La commande /config te redirige directement vers le Dashboard web pour une synchronisation en temps réel.

3

Teste le bot

Utilise /ping pour vérifier que le bot répond, puis explore les commandes avec /help.

💡 Conseil : Pour fonctionner pleinement, le bot doit avoir la permission Administrateur ou, au minimum, Gérer le serveur, Envoyer des messages, Intégrer des liens, Lire l'historique.

🎯 Système de Niveaux (XP)

Miaouscle Bot dispose d'un système de niveaux automatique et flexible.

📈

Auto

XP gagné à chaque message envoyé

🎨

Carte stylée

Carte de niveau générée à la montée

📢

Annonce

Canal configurable pour les level-up

⚡

2× Booster

Rôle Booster reçoit 2× l'XP

Formule de progression

XP nécessaire = 5 × (niveau³ + 15 × niveau² + 10 × niveau)

Exemples

NiveauXP requis (cumul)
1 → 2~100 XP
5 → 6~1 500 XP
10 → 11~8 500 XP
20 → 21~43 000 XP
💡 Les bots n'accumulent pas d'XP. Les messages en spam (moins de 60 s entre deux) ne comptent pas non plus.

Comment ça marche ?

1

Setup par l'admin bot

/ticket-setup channel:#support staff_role:@Staff — pose le panneau dans le canal indiqué.

2

Le membre clique "🎫 Ouvrir un ticket"

Un canal privé est créé automatiquement, visible uniquement par le membre, le rôle staff et le bot.

3

Le staff répond et clôture

Boutons persistants dans le ticket : 👤 Prendre en charge et 🔒 Fermer le ticket.

ℹ️ Le SLA est basé sur le plan du membre qui ouvre le ticket (admin d'un serveur Premium payant), pas sur le serveur de support. Un membre Premium+ d'un serveur tiers bénéficie du SLA 6 h.

Horaires d'ouverture

Optionnel — configure via /ticket-config pour limiter les ouvertures à des plages horaires précises (ex. lun–ven 9h–18h Europe/Paris). En dehors des horaires, un embed informatif est affiché au membre.

❓ Questions fréquentes
Comment ajouter le bot à mon serveur ?▼
Utilise le lien d'invitation, sélectionne ton serveur et autorise les permissions demandées. Le bot doit avoir les permissions Administrateur ou les permissions minimales listées dans la section Démarrage rapide.
Le bot ne répond pas, que faire ?▼
Vérifie que : 1) le bot est en ligne (/ping), 2) il a les permissions nécessaires dans le canal, 3) la commande est bien une commande slash (/). Si le problème persiste, contacte le support via /report.
Comment configurer les messages de bienvenue ?▼
Dashboard → onglet Messages. Sélectionne le canal et rédige ton message avec les variables {user}, {username}, {guild}, {count}. La personnalisation embed (couleur, image, footer) nécessite Premium.
Puis-je réinitialiser la configuration ?▼
Oui, Dashboard → onglet Général → bouton Réinitialiser Configuration. Tous les paramètres reviennent aux valeurs par défaut. L'action est irréversible.
L'XP ne monte pas, pourquoi ?▼
Vérifie que : 1) le système XP est activé dans le Dashboard, 2) l'utilisateur n'est pas muté, 3) les messages ne sont pas du spam (cooldown 60 s). Les bots ne reçoivent jamais d'XP.
Comment contacter le support ?▼
Utilise /report dans Discord, visite la page support, ou rejoint directement notre serveur Discord.
Le Premium est-il par serveur ou par compte ?▼
Le Premium est lié à un serveur Discord. Une fois activé sur un serveur, tous les membres et admins de ce serveur en profitent. Pour l'appliquer à plusieurs serveurs, il faut un abonnement par serveur.
