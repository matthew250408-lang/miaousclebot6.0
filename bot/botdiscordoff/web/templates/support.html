❓ Questions fréquentes

Comment configurer le bot ? ▼
Utilise /config sur ton serveur ou connecte-toi sur le Dashboard web pour accéder à tous les paramètres.
Comment ouvrir un ticket de support ? ▼
Rejoins notre serveur Discord et clique sur le bouton 🎫 dans le canal de support. Un canal privé sera créé pour toi. Les membres Premium+ ont une réponse garantie sous 6 h.
Quel est le délai de réponse ? ▼
Via ticket Discord :
📩 Basic — file d'attente standard
⚡ Premium — garanti sous 24 h
⭐ Premium+ — garanti sous 6 h

Via formulaire ci-contre — généralement sous 24 h.
Le bot ne répond plus, que faire ? ▼
Vérifie 1) le statut sur /status, 2) que le bot est bien présent sur le serveur, 3) qu'il a les permissions requises dans le canal. Si tout semble bon, signale le bug via le formulaire.
Comment activer le Premium sur mon serveur ? ▼
Consulte la page Premium pour découvrir les offres. Une fois abonné, utilise /premium-activate sur ton serveur pour l'activer.
Puis-je proposer une suggestion ? ▼
Absolument ! Utilise l'onglet "💡 Suggestion" dans le formulaire ci-contre, ou la commande /suggestion directement sur Discord.
